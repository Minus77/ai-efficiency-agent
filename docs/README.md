## 三条贯穿全套的前提

先说清楚可以省掉后面大量重复解释。

**一、没有材料就没有结论。** 无可用材料时诊断返回 409 并给可执行下一步，不生成场景。
代码层强制，不是提示词里的叮嘱。

**二、证据等级决定能说什么。** A 级给点估 + 区间，B 级只给区间，C 级任何位置都不出现
金额（含实施成本）。这条口径在 `config.FROZEN`，Agent 与自学习回路都改不了。

**三、自主度停在只读 + 建议。** 全部连接器只读，写操作只落本地工作区。
「该不该上 AI」是客户的经营决策，系统不替客户拍板。
