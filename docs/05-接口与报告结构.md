# 05 接口与报告结构

> 面向研发与集成方。服务由 `api.create_app()` 组装，默认 `http://127.0.0.1:8848`。

视图组装是纯函数（`api.VIEW_BUILDERS`）：入参是 `REPORT.json`，出参是前端要的结构。

供演示与回归用。新功能不要挂在旧路径上。

## 状态码语义

这些码是**结论的一部分**，不是纯粹的传输层错误：

- **409**：无可用材料无法诊断 / 连接器同步失败。detail 里带可执行的下一步
- **413**：单文件超 20MB
- **422**：指标不合法（非白名单或经营结果指标）、无基线就想要改善率、反馈缺角色
- **404**：客户或术语不存在。slug 不合法也归到这里——外部传入的非法 slug 一律当「不存在」
- **400**：未知连接器 key、删除预置客户

422 与 409 的 detail 都拼了 `next_action`，前端直接展示。写新接口时保持这个约定：
**错误消息要告诉用户下一步做什么，而不是只说失败了。**

值班提示：409 与 422 是设计意图，不是故障，不要把它们当 bug 去「修」。

## `REPORT.json` 顶层字段

```
client  delivery_form  admission_probe  scope  material_checklist
parents  cards  evidence  capabilities  feasibility  roi  aggregate
matrix  matrix_thresholds  roadmap  counter_review  counter_review_isolation
insights  gaps  assumptions  scorecard  security  guardian_checks
feedback  render_gate  observability  benchmarks
```

关键结构：

- **`cards`**（子场景）：`evidence_grade` `work_form` `quantifiable` `monthly_minutes`
  `evidence_refs`（**不可为空**）`conflict` `requires_human` `forensics_note`
- **`roi`**：以 `card_id` 为键。`tiers` 是保守/中性（`include_optimistic` 时加乐观），
  `direction_only=true` 表示不给金额。`calculation_trace` 与 `assumptions` 摊开计算过程
- **`aggregate`**：`naive_sum` / `deduped_sum` / `delta` / `dependency_released_total`
- **`matrix_thresholds`**：`benefit` 取本客户已量化场景收益的**中位数**（绝对阈值会随客户
  规模失准），`difficulty` 取七维加权 1–5 的中点 3.0。象限归属由服务端判定，前端只负责画
- **`render_gate`**：`body_ids` 进正文，`greyed_ids` 标灰及理由
- **`scorecard`**：`evidence_traceability` `grade_distribution` `work_form_distribution`
  `conflicts_escalated` `evidence_closure_rate`
- **`security`**：`injection_attempts_detected` / `injection_escaped`（后者必须为 0）
- **`insights`**：专家判断区，每条带 `source` ∈ `curated`/`llm`/`fallback`，**且不含金额**

## 六维记分卡

`evals.scorecard_of(report)` 把一次诊断折算成六维，权重与门禁在 `evals.py`：

| 维度 | 权重 | 门禁 |
|---|---|---|
| 任务成功 | 0.25 | ≥ 0.80 |
| 证据可追溯 | 0.25 | = 1.00 |
| 安全合规 | 0.20 | = 1.00 |
| 鲁棒性 | 0.15 | ≥ 0.85 |
| 效率成本 | 0.10 | — |
| 协作 | 0.05 | — |

「任务成功」直接取冻结黄金集 12 例的召回率（`evals/golden/cases.json`）。该集**永不参与
学习**；任一维度回退超 5% 即拒绝该批 playbook 更新并回滚。其中 `g-005`/`g-006`/`g-007`
三例专门验「取不到数据时是否老实说取不到」。

生产失败的最小复现放 `evals/failure_replays/`，修好后转入黄金集回归。
